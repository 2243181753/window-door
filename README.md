# 视窗之门 · Window Door

**适合摸鱼的免费开源 Mac 小窗工具：鼠标移入显示，移开隐藏。**

把目标窗口的实时画面放进可移动矩形，调节不透明度、跟随窗口，也可以开启本机摄像头守护。Swift / AppKit / ScreenCaptureKit 原生实现。

[下载软件](https://github.com/2243181753/window-door/releases/latest) · [使用指南](docs/使用指南.md) · [完整视频](#视频教程) · [English](README.en.md)

当前版本 **1.0.3** · **Apple 芯片 Mac** · **macOS 14+** · **MIT 开源**。Intel 构建尚未验证。

## 可以做什么

| 想要的效果 | 对应功能 |
| --- | --- |
| 鼠标移入看一眼，移开隐藏 | 鼠标检测 + 最小不透明度 0% |
| 保留小窗大小，随原窗口一起移动 | 跟踪目标 |
| 与原窗口同步大小和位置 | 跟随窗口 |
| 淡显或隐藏，按需切换 | 最大 / 最小不透明度 |
| 在小窗里点按钮、滚动、拖动 | 鼠标穿透，需辅助功能权限与目标应用支持 |
| 主人离开或出现他人时停止激活 | 摄像头守护，本机主人识别 |
| 根据观看角度、背景动静或手势控制显示 | 增强模式、角度学习、手势保护 |

## 下载与首次使用

1. [打开下载页](https://github.com/2243181753/window-door/releases/latest)，下载 `window-door-1.0.3-macos-arm64.zip` 并解压。
2. 打开“视窗之门”，按系统提示授予屏幕录制权限。
3. 点击菜单栏图标 → **选择窗口** → **开始**。
4. 先开启**鼠标检测**，关闭摄像头守护；开启**透明度平移**，最小值设为 **0%**、最大值设为 **100%**，体验移入显示、移出隐藏。

摄像头守护可在熟悉基础操作后再开启。需要后台鼠标操作时，再开启鼠标穿透并授予辅助功能权限。

**下载版尚未经过 Apple 公证，系统可能限制打开。** 授权与兼容性详情见 [使用指南](docs/使用指南.md) 和下方“权限与限制”。

源码下载：仓库 **Code → Download ZIP**，或版本页的 **Source code**。

## 构建与运行

安装 Xcode Command Line Tools。进入项目目录，执行：

```sh
./build.sh
open 视窗之门.app
```

VS Code 的任务中也提供构建、运行、测试和调试。调试配置需 VS Code 支持 LLDB。

```sh
./test.sh
```

`./verify.sh` 运行源码构建和界面检查。实际摄像头识别、真实鼠标操作及第三方软件兼容性还需手动测试。

仓库包含 SFace 模型与 ONNX Runtime，构建不需要重新下载。模型来源及校验值见 `Resources/model-manifest.json`。

## 权限与限制

屏幕录制用于采集选择的窗口；摄像头用于本机识别；辅助功能（设备控制和数据访问）用于操作目标窗口。首次运行按系统提示授权；修改代码、重新签名后可能需要重新授权。

构建脚本使用本机测试签名，没有 Developer ID 签名或 Apple 公证。下载后的运行体验取决于 macOS 的安全检查；正式分发仍需签名、公证。

最小化、切换桌面或受保护内容可能无法实时采集。后台控制依赖目标应用支持，且使用未公开系统接口，后续系统更新可能影响兼容性；此完整版不适合直接提交 Mac App Store。

矩形隐藏不会隐藏目标应用原始窗口。识别可能误判，不应当作保证安全的身份认证或系统隐私保护机制。

## 本地数据

画面和摄像头帧在内存中处理，不录制、不上传。主人特征、角度、手势和设置存本机；相应学习页面可清除学习资料。ONNX Runtime 遥测已关闭。仓库不包含用户登记资料或运行日志。

## 代码结构

`Sources/HoverPortal` 为 AppKit 界面、ScreenCaptureKit 采集、检测与输入控制；`Sources/FaceRuntime` 为 ONNX Runtime 包装；`Tests` 为验证程序。
